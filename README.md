## Projetos em destaque 📌

**[Barbershop - Sistema de agendamento](https://barbershop-psi-brown.vercel.app)**

Aplicação web desenvolvida para um cliente, com o objetivo de digitalizar o agendamento de serviços e facilitar a gestão de clientes, profissionais e horários.

O projeto envolve a implementação de funcionalidades orientadas às regras de negócio, integração com banco de dados e autenticação, buscando oferecer uma solução prática para as necessidades de uma barbearia.

**Stack:** Next.js · TypeScript · Supabase · PostgreSQL · Supabase Auth

**[Api de gerenciamento para restaurante](https://github.com/llorenzojorge/api-restaurant)**

API REST desenvolvida para o gerenciamento de recursos de um restaurante, incluindo mesas, sessões, produtos e pedidos. O projeto permite praticar operações CRUD, estruturação de endpoints, validação de dados, persistência de informações e organização da lógica da aplicação.

**STACK:** TypeScript · Node.js · Express · Zod · Knex.js · SQLite · Insomnia
